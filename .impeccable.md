# Impeccable — Project Design Context

## Design Context

### Users
Karyawan perusahaan (pilot 20–50 orang) yang belajar bahasa Inggris 5–10 menit per hari — di HP saat commute, di desktop saat jeda kerja. Sisi kedua: admin/HR yang mengelola konten & memantau. Job-to-be-done: membentuk kebiasaan harian, bukan sesi belajar panjang.

### Brand Personality
**Playful-professional.** Tiga kata: hangat, memotivasi, rapi. Terasa game saat dipakai (feedback instan, chunky, perayaan) tapi pantas dipresentasikan ke manajemen. Kepribadian datang dari warna + gerak + bunyi — TANPA maskot/ilustrasi karakter.

### Aesthetic Direction
Design system terkunci di `docs/design-system.md` (SATU-SATUNYA sumber token — patuhi):
indigo `#4F46E5` + navy `#1E1B4B` + semantik hijau/merah/amber; Nunito 600/800/900; radius besar; tombol "chunky 3D-lite" (border-bottom tebal, tekan-turun) sebagai signature; Lucide `strokeWidth 2.25`; light-only; emoji hanya untuk perayaan/kalender. Beranda: hero terang typographic (headline ink besar + satu chip highlight `.hero-mark`) — navy hanya untuk login & chrome sidebar desktop; bottom nav mobile = bar putih, item aktif pill brand-soft. Referensi rasa: Duolingo web (struktur), Dribbble Scanner/EverSync (hero & nav terang), mockup v2 di `.superpowers/brainstorm/*/content/`. Anti-referensi: dark-neon "AI dashboard", glassmorphism, corporate abu-abu datar.

### Design Principles
1. Daily first — semua layar mengarahkan ke satu aksi: MULAI sesi hari ini.
2. Feedback > dekorasi — gerak/bunyi hanya untuk umpan balik & perayaan.
3. Chunky adalah bahasa — elemen interaktif memakai idiom tekan-turun yang sama.
4. Jujur pada data — tidak menampilkan angka yang tidak valid (tanpa ranking antar-orang).
5. Mobile dan desktop sama-sama first-class; sesi selalu kolom fokus.
